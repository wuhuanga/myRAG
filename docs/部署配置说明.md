# RAG 后端项目部署配置说明

## 📁 项目结构

### 主要目录结构

```
myRAG/
├── app/                          # 后端 API 代码（您的模块化后端）
│   ├── __init__.py
│   ├── main.py                   # FastAPI 应用入口
│   ├── models.py                 # Pydantic 数据模型
│   ├── dependencies.py           # RAG 实例管理和依赖项
│   ├── routers/                  # API 路由模块
│   │   ├── __init__.py
│   │   ├── documents.py          # 文档操作路由
│   │   ├── query.py              # 查询路由
│   │   └── graph.py              # 图谱操作路由
│   └── internal/                 # 内部模块
│       ├── __init__.py
│       └── admin.py              # 管理路由
├── lightrag/                     # LightRAG 核心库
├── docs/                         # 文档目录
├── data/                         # 数据目录（运行时创建）
│   ├── rag_storage/              # RAG 存储目录
│   ├── inputs/                   # 输入文件目录
│   └── tiktoken/                 # Tiktoken 缓存
├── pyproject.toml                # Python 项目配置
├── Dockerfile                    # Docker 构建文件
├── docker-compose.yml            # Docker Compose 配置
├── env.example                   # 环境变量示例
└── README.md
```

### Entry Point（程序入口）

**主要入口文件**: `app/main.py`

**FastAPI 应用对象**:
```python
app = FastAPI(
    title="RAG Backend API",
    description="Modular RAG backend with multi-instance support",
    version="3.0.0"
)
```

**启动命令**:
```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

**默认端口配置**:
- **LightRAG 原生 API**: `9621`（在 Dockerfile 和 env.example 中）
- **您的模块化 API**: `8000`（在 app/main.py 中，可自定义）

## 🐳 Docker 部署配置

### 云服务器部署建议

#### 方式一：使用现有 Dockerfile（LightRAG 原生）

**特点**:
- 包含完整的 LightRAG 环境
- 默认端口 9621
- 适合运行原生 LightRAG API

**Dockerfile 内容**:
```dockerfile
# Build stage
FROM python:3.12-slim AS builder
WORKDIR /app

# 安装构建依赖
RUN pip install --upgrade pip setuptools wheel
RUN apt-get update && apt-get install -y \
    curl build-essential pkg-config \
    && rm -rf /var/lib/apt/lists/* \
    && curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y

# 复制项目文件
COPY pyproject.toml setup.py ./
COPY lightrag/ ./lightrag/

# 安装依赖
ENV PATH="/root/.cargo/bin:${PATH}"
RUN pip install --user --no-cache-dir --use-pep517 .
RUN pip install --user --no-cache-dir --use-pep517 .[api]

# 安装默认存储和文档处理依赖
RUN pip install --user --no-cache-dir \
    nano-vectordb networkx \
    openai ollama tiktoken \
    pypdf2 python-docx python-pptx openpyxl

# Final stage
FROM python:3.12-slim
WORKDIR /app

RUN pip install --upgrade pip setuptools wheel
COPY --from=builder /root/.local /root/.local
COPY ./lightrag ./lightrag
COPY setup.py .

RUN pip install --use-pep517 ".[api]"
ENV PATH=/root/.local/bin:$PATH

# 创建数据目录
RUN mkdir -p /app/data/rag_storage /app/data/inputs

ENV WORKING_DIR=/app/data/rag_storage
ENV INPUT_DIR=/app/data/inputs

EXPOSE 9621

ENTRYPOINT ["python", "-m", "lightrag.api.lightrag_server"]
```

**使用方法**:
```bash
# 构建镜像
docker build -t myrag:latest .

# 运行容器
docker run -d \
  --name myrag \
  -p 9621:9621 \
  -v $(pwd)/data/rag_storage:/app/data/rag_storage \
  -v $(pwd)/data/inputs:/app/data/inputs \
  -v $(pwd)/.env:/app/.env \
  --env-file .env \
  myrag:latest
```

#### 方式二：自定义 Dockerfile（运行 app 模块化 API）

创建 `Dockerfile.app`:

```dockerfile

    build-essential \

COPY app/ ./app/
COPY UCD_RAG.py ./

# 安装 Python 依赖
RUN pip install --no-cache-dir -e ".[api]"

# 安装额外依赖
RUN pip install --no-cache-dir \
    textract \

# 设置环境变量

ENV WORKING_DIR=/app/data/rag_storage

# 启动命令
```

**构建和运行**:
```bash
# 构建镜像
docker build -f Dockerfile.app -t myrag-api:latest .

# 运行容器

  --name myrag-api \
  -p 8000:8000 \
  -v $(pwd)/data:/app/data \
  -v $(pwd)/.env:/app/.env \
  --env-file .env \
  myrag-api:latest
```

- **CPU**: 8+ 核
- **内存**: 32GB+

```bash
# .env 配置
```
